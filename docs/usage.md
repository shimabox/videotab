# 画面の使い方

画面でタブ譜を作る流れと、画面を使わずに通して実行する方法の詳しい説明です。[README に戻る](../README.md)

## 画面を開く

```sh
make web              # または: uv run videotab serve
```

ブラウザに画面が開きます（http://127.0.0.1:8765/ 。手元のマシンの中だけで動きます）。

videotab は、動画をネットから取ってくる機能を持ちません。書き起こしたい動画ファイルは、自分で用意してください。

## タブ譜を作る

1. 動画ファイル（.mp4 .m4v .mov .webm .mkv .avi、4 GB まで）を「動画ファイルを選ぶか、ここにドロップ」の欄で選ぶか、欄にドロップします。
2. 題名は、ファイル名（拡張子を除く）から付きます。題名・動画の作成者・元動画のページ（https:// で始まるもの）は、あとから曲の詳細の「曲の情報」で入れたり直したりできます（下の[曲の情報を直す](#曲の情報を直す)）。作成者と元動画のページは、できあがったタブ譜のページに出ます。
3. 読み取りに使う AI（既定は Claude Code）を選んで「タブ譜を作る」を押します。必要なら、読み取りのモデルと推論の強さも選べます。選ばなければ、普段の設定で動きます。
4. 送っている間は進み具合が出ます。「中止」で送るのをやめられます。受け取った動画は ffprobe で中身を確かめてから取り込みます（動画として読めなければ、その場で断ります）。
5. 次の段が順に進みます（1 曲に数分〜十数分）。

   取り込み → 画像の切り出し → 帯と線の検出 → ページ分け → 読み取り → タブ譜の組み立て → 時刻の照合

6. できあがると、その画面でタブ譜を表示・再生できます。「別のタブで開く」で単独のページにもなります。
7. タブ譜はダウンロードできます（下の[ダウンロードの形式](#ダウンロードの形式)）。

カメラでパソコンの画面を撮影した動画でも、薄い線や小さな傾き・上下の揺れ・弦の間隔の伸縮を補正して検出します。ただし、ぼけや映り込みでフレット番号を読み違えることがあります。可能なら画面録画の動画を使ってください。

タブが見えたフレームが少ない手撮りの動画は紙の楽譜として扱います。画面のタブ譜なら、やり直すで戻せます（詳細の「やり直す」で楽譜の種類を「画面のタブ譜」にします）。どちらと判定したかは「帯と線の検出」の段の結果欄に出ます。詳しくは [紙の楽譜から書き起こす](paper.md#動画の楽譜の種類) を見てください。

同じファイルをもう一度送ると、別の曲として新しく作ります。途中で止まった曲を続けるときは、その曲の「やり直す」を使います。

動画の取り込み・画像の切り出し・帯と線の検出・ページ分け・検査・組み立て・時刻の照合は、videotab 自身が決まったルールで行います。画像からフレット番号・リズム・記号を読むのは、videotab が裏で起動する Claude Code（`claude -p`）か Codex（`codex exec`）です。API キーは使わず、手元でログイン済みのコマンドとその利用枠で動きます。読み取りの手順は [AGENTS.md](../AGENTS.md) にあります。

## 読み取りの分担

- 読み取りでは、ページを最大 4 つのまとまりに分け、まとまりごとに AI を起動して同時に読ませます。
- となり合うまとまりの境目のページは両方で読みます。食い違いや抜けは、まとめ役の AI が画像を見直して解きます。

## 読み取りのモデルと推論の強さ

- 画面で曲ごとに選べます。選ばなければ、普段の Claude Code / Codex の設定に合わせます。
- 選んだ値はその曲の読み取りだけに効き、普段の設定は書き換えません。
- どの値で読んだかは、「読み取り」の段の結果欄とログで確かめられます。

詳しくは [読み取りのモデルと推論の強さ](model-settings.md) を見てください。

## 止める

実行中の曲は、曲の詳細の右上にある「止める」で止められます。動いている処理（読み取りの AI や画像の切り出しなど）を止め、曲は「中断」になります。

- 止めた段は未実行に戻ります。「やり直す」と、その段の最初から始まります。済んだ段はやり直しません。
- 順番待ちの曲は「順番待ちから外す」で外せます。
- `videotab run` で動いている曲は、画面からは止められません（端末で Ctrl+C を押してください）。

## やり直す

途中で失敗した段や、結果に納得がいかない段は、「やり直す」からその段だけやり直せます。やり直すときに、読み取りに使う AI や、モデルと推論の強さを切り替えることもできます。

動画の曲では、「楽譜の種類」（画面のタブ譜 / 紙の楽譜）も変えられます。変えると「帯と線の検出」の段からやり直します。

## 曲の情報を直す

題名・動画の作成者・元動画のページは、あとから曲の詳細の「曲の情報」で入れたり直したりできます。実行中・順番待ちの曲では出ません。

- 保存すると、`meta.json` と `score.json`（題名・副題・作成者）に書きます。
- 副題は、雛形のまま（「○○ さんの動画のタブ譜から書き起こし」）のときだけ新しい作成者に合わせます。`score.json` で手で直した副題は残します。
- 題名を空のまま保存すると、元の動画のファイル名（拡張子を除く）に戻ります。
- 作成者を空にすると、楽譜から作成者の表記が消えます。元動画のページを空にすると、リンクが消えます。元動画のページは https:// で始まる URL だけを入れられます。
- 読み取りまでの段が済んだ曲は、「保存してタブ譜に反映」で「タブ譜の組み立て」の段から組み立て直し、タブ譜に反映します。読み取りはやり直さないので、AI の利用枠は使いません。
- 読み取りまでの段が済んでいない曲は「保存する」で保存だけを行います。タブ譜には、「やり直す」で続きを実行して組み立てたときに出ます。

## 読み取りの報告とログ

- 画面の「読み手の報告」で、読み取りの AI とまとめ役の AI の報告（自信のない小節、曲の構成）を見られます。ログも画面で見られます。
- 報告は日本語で返すよう頼んでいます（英語で返ったときは、そのまま出ます）。
- 報告は、見出し・箇条書き・太字・コードを整えて表示します。報告の中の HTML は文字として出るだけで、動きません。

## 開始時刻と終了時刻

曲の見出しの下には開始時刻が出ます。できあがった曲と失敗した曲には、終了時刻（最後に終わった段の時刻）も並びます。

## 曲を消す

要らなくなった曲は、曲の詳細の右上にある「この曲を消す」で作業フォルダごと消せます。確認のあと消し、元に戻せません。消えるものは [作業フォルダ](commands.md#作業フォルダ) を見てください。

## ダウンロードの形式

| 形式 | 使いみち |
|---|---|
| HTML | 1 ファイルで、オフラインでも表示できる（画面の「HTML をダウンロード」） |
| Guitar Pro（`.gp`） | Guitar Pro・TuxGuitar・MuseScore などで開いて編集・練習できる |
| MIDI（`.mid`） | DAW や練習アプリで鳴らせる |
| alphaTex | videotab が楽譜を作るときのテキストのデータ |
| 印刷 / PDF | ブラウザの印刷から PDF に保存できる |

- Guitar Pro・MIDI・alphaTex・印刷は、タブ譜のページの操作バーにあります（ダウンロードした HTML でも使えます）。
- できあがる HTML は alphaTab を埋め込んだ 1 ファイルで、オフラインでも表示できます（再生だけは音源データをネットから読みます）。

## タブ譜が写っていない動画のとき

帯と線の検出でタブ譜の 6 本線が見つからなければ、タブ譜が写っていない動画と判断します。取り込んだ動画と切り出した画像を消して止まります。この曲を「やり直す」と、取り込みの段が「動画がありません」で止まります。別の動画で新しく作ってください。紙を撮った動画だったときは、`uv run videotab run 動画.mp4 --paper` で紙の楽譜として取り込み直します。

## 画面を使わずに通して実行する（videotab run）

画面と同じ流れを、コマンドで実行できます。

```sh
make run VIDEO=動画.mp4         # または: uv run videotab run 動画.mp4
```

題名・動画の作成者・元動画のページは `--title` / `--creator` / `--source-url` で、モデルと推論の強さは `--model` / `--effort` で選べます。

```sh
uv run videotab run 動画.mp4 --creator 作成者 --source-url https://example.com/... --model opus --effort max
```

- 動画ファイルを渡すたびに、新しい作業フォルダ（`work/<ID>/`）に取り込みます。途中で止まったときは、表示される `videotab run <ID>` で同じ曲を続けます（`--root` で置き場を変えたときは、その指定も含めて表示されます）。
- 選び方の詳しい決まりは [読み取りのモデルと推論の強さ](model-settings.md#videotab-run-で選ぶ) にあります。
- 同じ曲を、画面と `videotab run` で同時に実行することはできません（`job.lock`）。
- 段ごとにコマンドを 1 つずつ動かす方法は [コマンド](commands.md) にあります。
