# 紙の楽譜から書き起こす

バンドスコアなど、複数の楽器が並んだ紙の楽譜から、指定したパートの TAB を書き起こします。
紙をめくりながら撮影した動画、PNG・JPEG の写真、画像の ZIP、PDF、画像フォルダを使えます。
6 弦ギターと 4 弦ベースに対応します。五線だけのパートは対象外です。

## 画面から使う

1. ファイルを選ぶかドロップします。複数の写真はページ順の名前を付けた ZIP にしてください。
2. 紙を撮影した動画では「楽譜の種類」を「紙の楽譜」にします。写真・PDF・ZIP は自動で切り替わります。
3. 楽譜に書かれたパート名（例: `Guitar I`、`Guitar II`、`Bass`）と弦数を指定します。
4. 読み取りに使う AI を選んで「タブ譜を作る」を押します。
5. 詳細の「選んだパートと元ページを確認」で切り出した段と元ページを開き、取り違えや欠けを確認します。

パートや弦数を変える場合は、詳細の「やり直す」で変更します。ページとパートの選択からやり直し、前のパートの読み取り結果は `history/` に移します。
前の見出しも履歴に残し、チューニングとカポは新しいパートの標準値から読み直します。
題名・テンポ・拍子など、曲全体の見出しは引き継ぎます。

## コマンドから使う

```sh
uv run videotab run 紙の楽譜.mp4 --paper --part 'Guitar I' --strings 6
uv run videotab run 楽譜.pdf --part Bass --strings 4 --engine codex
uv run videotab run 写真フォルダ --part 'Guitar II'
uv run videotab run ページの写真.zip --part 'Guitar I'
```

写真・PDF・ZIP・画像フォルダは紙の楽譜として取り込まれます。
パート名の既定は `Guitar I`、弦数の既定は 6 です。ベースでは `--strings 4` を指定してください。
読み取りのモデル・推論の強さは、既存の `--model`・`--effort` を使えます。
ページ選択にも読み取りと同じ AI と設定を使います。
Codex には候補一覧・担当する段の拡大画像・元ページを画像として添付します。
まとめ役には、問題の小節がある段とその前後を添付して照合します。

PDF の取り込みには Poppler の `pdftoppm` が必要です。

```sh
brew install poppler                     # macOS
sudo apt install poppler-utils           # Ubuntu / Debian
```

写真・PDF・ZIP は 256 MB、1〜200 ページまでです。ZIP の画像は展開後の合計 1 GB までです。画像は PNG・JPEG を使います。
PDF は長辺 2400px の画像に変換します。暗号化された PDF は使えません。
画像フォルダと ZIP の順序はファイル名順です。`001.png`、`002.png` のように桁をそろえてください。

## 処理と確認

- 動画は 4 秒ごとの時間帯から鮮明な候補画像を選びます。元フレームもすべて残します。
- AI が元画像を見て、同じ紙のページの重複を除き、指定パートの段を選びます。候補にないページは元フレームを探します。
- 選択した段には、リズムを読む五線と TAB、奏法記号を含めます。ページ全体も保存し、テンポ・拍子・繰り返し・小節番号を照合します。
- TAB の線を複数の位置で確認できた段だけ、曲がりと縦方向の間隔の変化を補正します。確認できない段は補正せず、弦の印も推測で付けません。
- 読み取り結果を既存の `check` で検査し、つなぎ目の食い違い・小節の抜けを解決して HTML と alphaTex を出力します。

紙をめくる時刻は演奏時刻ではないため、テンポ推定や時刻照合には使いません。
テンポの表記がない場合は、再生用に仮の 120 BPM を設定し、読み手の報告に残します。
拍の合計・タイ・記法の検査は通常どおり行います。

ぼけ、指による遮蔽、画面外に切れた小節は、拡大や補正で元の情報を取り戻せません。
読み手の報告と元ページを確認し、必要なページを鮮明に撮り直してください。
ページやパートの選択は AI の判断なので、切り出しの確認も必要です。

## 領域を手で調整する

読み取り前のページ選択は `work/<ID>/paper/layout.json` に保存されます。
座標を直したらページの拡大からやり直せます。

```sh
uv run videotab run <ID> --step pages
```

```json
{
  "pages": [
    {
      "frame": 2,
      "regions": [
        {"box": [0.05, 0.20, 0.95, 0.40], "tab": [0.05, 0.30, 0.95, 0.38]}
      ]
    }
  ],
  "warnings": []
}
```

- `frame`: `frames/` の元フレーム番号。
- `pages`: 紙のページ順。見開きでは同じフレームを左右のページに分けて使えます。
- `regions`: そのページにある指定パートの段を、上から読む順に並べます。
- `box`: 対応する五線・TAB・奏法記号を含む範囲。
- `tab`: TAB の線を含む範囲。`box` の内側にします。
- 座標は元画像の幅・高さを 1 とした `[左, 上, 右, 下]` です。

`--step strip` は AI にページとパートを選び直させるため、手で調整した領域も作り直します。
`videotab zoom <ID> フレーム番号` は、選択済みフレームなら同じ段を再拡大し、それ以外は元ページ全体を拡大します。

既存の画像でページ候補だけ確認するときは、次のコマンドを使えます。ここでは AI を起動しません。

```sh
uv run videotab paper <ID> --part 'Guitar I' --strings 6
```

`--part`・`--strings` を省略すると、保存済みのパート・弦数をそのまま使います（保存がなければ `Guitar I`・6 弦）。

候補一覧は `paper/candidates/`、領域と報告は `paper/layout.json`・`paper/notes.md`、読み取り画像と一覧は `pages/` にあります。
ページやパートを選べずに止まっても、元動画と元画像は残ります。
