# 紙の楽譜から書き起こす

バンドスコアなど、複数の楽器が並んだ紙の楽譜から、選んだパートの TAB を書き起こします。[README に戻る](../README.md)

- 使えるもの: 紙をめくりながら撮影した動画、PNG・JPEG の写真、写真をまとめた ZIP、PDF、画像フォルダ
- 対応するパート: 6 弦ギターと 4 弦ベースの TAB（五線だけのパートは書き起こせません）

## 画面から使う

1. ファイルを選ぶかドロップします。複数の写真は、ページ順の名前を付けて ZIP にまとめます。
2. 読み取りに使う AI を選んで「タブ譜を作る」を押します。
3. AI が楽譜にあるパートを洗い出すと、曲の状態が「パートの選択待ち」になって止まります。
4. 詳細の「パートを選ぶ」で書き起こすパートを選び、弦数を確かめて「このパートで続ける」を押します。
5. できあがったら、詳細の「選んだパートと元ページを確認」で、切り出した段と元のページに取り違えや欠けがないか確かめます。

写真・PDF・ZIP は、いつも紙の楽譜として扱います。動画は、紙を撮ったものか画面のタブ譜かを自動で見分けます（下の[動画の種類の見分け方](#動画の種類の見分け方)）。

「パートを選ぶ」の一覧には、楽譜に書かれた名前がそのままの綴りで並びます。

- TAB のないパート（五線だけのパート）は選べません。
- 弦数には TAB の線の本数からの見込みが入っています。違っていたら直します。
- 選んだあとも、詳細の「楽譜で見つかったパート」で一覧を見られます。

## コマンドから使う

```sh
uv run videotab run 楽譜.pdf          # 写真・ZIP・画像フォルダ・紙を撮った動画も同じ
```

パートを洗い出したところで、一覧と続け方を出して止まります（終了コード 4）。

```
楽譜で見つかったパート:
  1. Guitar I   TAB あり  6 弦の見込み  確信度 高  ページ 1, 2
  2. Guitar II  TAB あり  6 弦の見込み  確信度 高
  3. Bass       TAB あり  4 弦の見込み
  4. Drums      TAB なし（選べません）
続きは、書き起こすパートを --part で指定します（弦数が見込みと違うときは --strings 4 か 6 を付ける）:
  videotab run <ID> --part 'Guitar I'
  videotab run <ID> --part 'Guitar II'
  videotab run <ID> --part Bass
一覧に無い名前も指定できます。洗い出しからやり直すなら: videotab run <ID> --step strip
```

表示された名前を `--part` に渡すと続きます。

```sh
uv run videotab run <ID> --part 'Guitar II'
uv run videotab run <ID> --part Bass --strings 4
```

パート名が分かっているときは、最初から `--part` を付ければ止まらずに最後まで進みます（洗い出しの AI も起動しません）。

```sh
uv run videotab run 楽譜.pdf --part Bass --strings 4
uv run videotab run 紙の楽譜.mp4 --paper --part 'Guitar I'
```

- 動画に `--part`・`--strings` を付けるときは、`--paper` も付けます。
- 弦数は `--strings` が優先です。選択待ちの曲で省くと、取り込むときに `--strings` で指定した弦数、一覧の見込み、6 の順で決めます。最初から `--part` を付けて `--strings` を省くと 6 です。ベースは `--strings 4` を付けてください。
- パートを選んだあとの曲で `--part` だけを変えると、弦数は前のままです。
- `--part` には一覧に無い名前も指定できます。そのときは注意を 1 行出して、その名前のまま進めます。
- 選択待ちの曲で `videotab run <ID>` をもう一度実行すると、AI を起動せずに一覧を出し直します。
- 画面で始めた曲をコマンドで続けることも、その逆もできます。
- 読み取りのモデルと推論の強さは `--model`・`--effort` で選べます。ページとパートの選択にも同じ AI と設定を使います。

## 用意するものと上限

- PDF には Poppler の `pdftoppm` が必要です。

  ```sh
  brew install poppler                     # macOS
  sudo apt install poppler-utils           # Ubuntu / Debian
  ```

- 写真・PDF・ZIP は 256 MB、1〜200 ページまで。ZIP の画像は展開後の合計 1 GB まで。画像は PNG・JPEG です。
- PDF は長辺 2400px の画像にして使います。暗号化された PDF は使えません。
- 画像フォルダと ZIP は、ファイル名の順をページ順にします。`001.png`、`002.png` のように桁をそろえてください。

## 動画の種類の見分け方

動画は、「帯と線の検出」の段が、画面のタブ譜か紙を撮ったものかを見分けます。AI は使いません。

- 手撮りの補正が要る動画で、タブが見えたフレームが 1/3 以下、補正で線が取れたフレームが 1/2 以下なら、紙を撮った動画とします。
- それ以外は画面のタブ譜です。画面録画の動画は、必ず画面のタブ譜になります。
- どちらにしたかと根拠の数値は、段の結果欄に出ます（例「画面のタブ譜として検出（タブが見えたフレーム 22/24）」「紙を撮った動画と判断」）。

判定が違っていたら、楽譜の種類を変えて「帯と線の検出」の段からやり直します。変えた種類は利用者が決めたものとして覚え、以後は自動で見分けません。

- 画面: 詳細の「やり直す」にある「楽譜の種類」を変えます（動画の曲だけに出ます）。
- コマンド: `--paper` か `--screen` を付けます。

  ```sh
  uv run videotab run <ID> --step strip --paper     # 紙の楽譜にする
  uv run videotab run <ID> --step strip --screen    # 画面のタブ譜に戻す
  ```

  `--paper` と `--screen` は同時に付けられません。`--step` は `strip` かそれより前の段にします（省くと `strip` から）。`--screen` は動画の曲だけに使えます。今と同じ種類を指定したときは、何も切り替えません。

- 紙の楽譜に変えると、パートを洗い出して選択待ちで止まります。パート名も指定すれば（画面ではパート欄、コマンドでは `--paper --part 'Guitar I'`）、止まらずに進みます。
- 画面のタブ譜に戻しても、`paper/` の中身（候補・洗い出したパート・領域）は残ります。パートを選んでいた曲では、前の見出しを `history/` に残し、チューニングとカポを 6 弦の標準に戻して読み直します。
- 三脚で固定して撮った紙の動画は、画面のタブ譜と判定されることがあります。そのときは紙の楽譜に変えてください。
- 紙の楽譜として取り込むことが分かっている動画は、最初から `--paper` を付けると見分けを省きます。
- タブ譜の線がまったく見つからない動画は、タブ譜が写っていないと判断して、動画と画像を消して止まります。紙を撮った動画だったときは、`uv run videotab run 動画.mp4 --paper` で取り込み直します。

## パートを選び直す・変える

詳細の「やり直す」を使います。

- 選択待ちの曲で、パート欄を空のまま「ページとパートの選択」からやり直すと、洗い出しからやり直します。
- パート欄に名前を入れてやり直すと、その名前と弦数で、ページとパートの選択に進みます。
- パートを選んだあとでパートや弦数を変えると、ページとパートの選択からやり直します。前のパートの読み取り結果と見出しは `history/` に移し、チューニングとカポは新しいパートの標準値から読み直します。題名・テンポ・拍子など曲全体の見出しは引き継ぎます。
- パートを選んだ曲では、パート欄を空にしてやり直しても、選んだパートのまま進みます。

## 中で何をしているか

1. 候補を作る: 動画は 4 秒ごとにいちばん鮮明なフレームを選びます。写真・PDF は全ページを使います。元のフレームもすべて残します。
2. パートを洗い出す（AI）: 候補を見て、楽譜にあるパートの名前・TAB の有無・弦数の見込みを一覧にします。パートを最初から指定した曲では行いません。
3. ページとパートの段を選ぶ（AI）: 同じページの重複を除き、選んだパートの段を選びます。段には、リズムを読む五線と TAB、奏法記号を含めます。ページ全体も残し、テンポ・拍子・繰り返し・小節番号の確認に使います。
4. 段を補正して拡大する: TAB の線を複数の位置で確かめられた段だけ、紙の曲がりと縦方向の間隔の変化を補正します。確かめられない段は補正せず、弦の印も推測で付けません。
5. 読み取りと組み立て: 動画のタブ譜と同じく、読み取り・検査・食い違いの解決を行い、HTML と alphaTex を出します。読み手には、担当する段の拡大画像と元ページを渡します（Codex には画像として直接添付します）。

紙をめくる時刻は演奏の時刻ではないので、テンポの推定や時刻の照合には使いません。テンポの表記がなければ、再生用に仮の 120 BPM にして、読み手の報告に残します。

## うまくいかないとき

- **数字がぼけている・指で隠れている・画面の外に切れている**: 拡大や補正では元の情報を取り戻せません。読み手の報告と元ページで確かめ、そのページを鮮明に撮り直してください。撮るときは、1080p 以上で、本をしっかり開いてのどの曲がりを減らし、各ページを 1〜2 秒止めると読みやすくなります。
- **望むパートが一覧に無い**: 「やり直す」で洗い出しからやり直すか、パート名を入れてやり直します（[パートを選び直す・変える](#パートを選び直す変える)）。
- **TAB のあるパートが 1 つも見つからない**: 選択待ちにはせず、AI が書いた理由を添えて「ページとパートの選択」の段が失敗します。
- **動画の種類の判定が違う**: [動画の種類の見分け方](#動画の種類の見分け方)の手順で変えます。
- **切り出した段がずれている**: ページとパートの選択は AI の判断です。下の[領域を手で調整する](#領域を手で調整する)で直せます。

ページやパートを選べずに止まっても、元の動画と画像は残ります。

## 細かい調整

### 洗い出したパートの一覧（`paper/parts.json`）

```json
{
  "parts": [
    {"name": "Guitar II", "tab": true, "strings": 6, "confidence": "high", "frames": [2, 5]},
    {"name": "Drums", "tab": false, "strings": null}
  ],
  "warnings": ["3 ページ目は右端が切れていて楽器名が読めません"]
}
```

| 項目 | 中身 |
|---|---|
| `name` | 楽譜に書かれたパート名。綴りは変えない（80 文字まで、改行などの制御文字は使えない） |
| `tab` | TAB の段があるか。`false` のパートは選べない |
| `strings` | TAB の線の本数から見込んだ弦数（4 か 6）。見込めなければ `null`（選ぶときの初期値は 6） |
| `confidence` | 名前と TAB の有無の確かさ（`high`・`medium`・`low`）。省略できる |
| `frames` | そのパートを確かめた元フレームの番号。省略できる |

- パートは 40 個までです。AI の報告は `paper/parts.md` にあり、詳細の「読み手の報告」に「パートの洗い出し」として出ます。
- videotab は一覧を読むたびに、名前の文字と長さ・重複・件数・値の型を検査します。通らない一覧は空として扱います（洗い出しからやり直せます）。
- 選択待ちの間も、元画像・候補・一覧は残ります。画面を閉じて開き直しても選択待ちのままです。

### 領域を手で調整する（`paper/layout.json`）

ページとパートの段の選択は `paper/layout.json` に残ります。座標を直したら、ページの拡大からやり直します。

```sh
uv run videotab run <ID> --step pages
```

```json
{
  "pages": [
    {"frame": 2, "regions": [{"box": [0.05, 0.20, 0.95, 0.40], "tab": [0.05, 0.30, 0.95, 0.38]}]}
  ],
  "warnings": []
}
```

| 項目 | 中身 |
|---|---|
| `pages` | 紙のページ順。見開きでは、同じフレームを左右のページに分けて使える |
| `frame` | `frames/` の元フレームの番号 |
| `regions` | そのページにある選んだパートの段を、上から読む順に並べる |
| `box` | 段の五線・TAB・奏法記号を含む範囲 |
| `tab` | TAB の線を含む範囲（`box` の内側） |

座標は、元画像の幅・高さを 1 とした `[左, 上, 右, 下]` です。パートを選んだ曲で `--step strip` からやり直すと、AI が段を選び直すので、手で直した領域も作り直されます。

### そのほかのコマンド

- `videotab zoom <ID> フレーム番号`: 選んだ段のあるフレームなら同じ段を、それ以外は元ページ全体を拡大します。
- `videotab paper <ID> [--part 名前] [--strings 4|6]`: AI を起動せずに、候補の一覧だけを作ります。パートを省くと保存済みの指定を使い、それも無ければパートを選ぶ前の曲として保存します。

### 作業フォルダの中身

| パス | 中身 |
|---|---|
| `paper/candidates/` | 候補の一覧の画像 |
| `paper/parts.json` / `paper/parts.md` | 洗い出したパートと AI の報告 |
| `paper/layout.json` / `paper/notes.md` | 選んだ段の領域と AI の報告 |
| `pages/` | 読み取り用の拡大画像と一覧 |
