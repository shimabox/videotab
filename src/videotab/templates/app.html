手元の動画や紙の楽譜の写真から、タブ譜を 1 枚の楽譜に書き起こします

読み取り

曲

    動画か楽譜のファイルを選ぶかドロップして「タブ譜を作る」を押すと、ここに進み具合が出ます。

    使う前に知っておくこと

    • タブ譜の数字やリズムは、切り出した画像を Claude Code か Codex（AI）に渡して読み取ります。あなたがログインしている Claude Code / Codex の利用枠（契約ごとに決まっている、AI を使える量）を使います。
    • モデルは AI の種類、推論の強さは AI がどれだけ時間をかけて考えるかです。強いほど丁寧になりやすいですが、遅く、利用枠も多く使います。
    • 1 曲に数分〜十数分かかります。
    • 動画・画像・タブ譜は、この Mac の videotab のフォルダの中の work フォルダに保存します。

    免責事項

    • 書き起こしは画像処理と AI による自動のもので、誤りを含むことがあります。正確さは保証しません。元の動画と照らして確かめてください。
    • 動画・切り出した画像・書き起こしたタブ譜には、楽曲や元の動画・タブ譜の作り手の著作物が含まれます。私的な練習の範囲で使い、公開・再配布・販売をしないでください。
    • videotab は現状のまま提供され、使用によって生じた損害について作者は責任を負いません。
